# ตั้งค่ารูปโปรไฟล์บน Google Drive

รูปทั้งหมดอยู่ในโฟลเดอร์ Drive โฟลเดอร์เดียว ชื่อไฟล์คือ `<เลขนศ>.jpg` เว็บผูกรูปกับโปรไฟล์ด้วยเลขนศ. เหมือนเดิม
ตัวกลางระหว่างเว็บกับ Drive คือ Google Apps Script (`Code.gs`) ซึ่งทำ 2 อย่าง:

- **GET**: ส่งรายการ `เลขนศ → fileId` ให้เว็บ (cache 5 นาที)
- **POST**: รับรูปจากเว็บ ตรวจว่าคนที่ล็อกอินเป็นเจ้าของเลขนศ. นั้น (หรือเป็นแอดมิน) แล้วบันทึกลง Drive แทนรูปเดิม (รูปเดิมไปอยู่ในถังขยะ กู้คืนได้ 30 วัน)

## 1. สร้างโฟลเดอร์ใน Drive

1. สร้างโฟลเดอร์ เช่น `CN25-photos`
2. คลิกขวา → **แชร์** → การเข้าถึงทั่วไป: **ทุกคนที่มีลิงก์** → **ผู้มีสิทธิ์อ่าน**
   (จำเป็น เพื่อให้เว็บแสดงรูปได้โดยไม่ต้องล็อกอิน Google)
3. คัดลอก id ของโฟลเดอร์จาก URL: `https://drive.google.com/drive/folders/<FOLDER_ID>`

## 2. สร้าง Apps Script

1. ไปที่ <https://script.google.com> → **โปรเจกต์ใหม่** ตั้งชื่อ `CN25 Photo API`
2. ลบโค้ดเดิม แล้ววางเนื้อหาไฟล์ `apps-script/Code.gs` ทั้งไฟล์ → บันทึก
3. ⚙️ **การตั้งค่าโปรเจกต์** → **พร็อพเพอร์ตีของสคริปต์** → เพิ่ม:

   | พร็อพเพอร์ตี | ค่า |
   |---|---|
   | `FOLDER_ID` | id โฟลเดอร์จากข้อ 1 |
   | `FIREBASE_API_KEY` | ค่า `apiKey` ใน `firebaseConfig` ของ `index.html` |
   | `ADMIN_IDS` | `6910616249` (หลายคนคั่นด้วย `,`) |
   | `SITE_ORIGIN` | `https://cn25.peemcn25.dev` |

4. **ทำให้ใช้งานได้ (Deploy)** → **การทำให้ใช้งานได้รายการใหม่** → ประเภท **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. กดอนุญาตสิทธิ์ (Drive + เชื่อมต่อบริการภายนอก) แล้วคัดลอก **URL เว็บแอป** ที่ลงท้ายด้วย `/exec`

> แก้โค้ดใน Apps Script ภายหลัง ต้อง Deploy → **จัดการการทำให้ใช้งานได้** → แก้ไข → เวอร์ชันใหม่ ไม่อย่างนั้น URL เดิมยังรันโค้ดเก่า

## 3. ใส่ URL ในเว็บ

ใน `index.html` แก้บรรทัด:

```js
const PHOTO_API_URL = '';
```

เป็น URL จากข้อ 2 แล้ว push ขึ้น GitHub

ตราบใดที่ `PHOTO_API_URL` ยังว่าง เว็บจะใช้รูปจาก `assets/` แบบเดิม

## 4. ย้ายรูปเดิมขึ้น Drive

เลือกได้ 2 แบบ

- **ลากไฟล์เอง**: ลากไฟล์ `assets/69xxxxxxxx.*` ทั้งหมดลงโฟลเดอร์ Drive (ชื่อไฟล์ต้องเป็นเลขนศ.) รอ ~5 นาทีให้ cache หมดอายุ
- **ผ่านหน้า ADMIN** (แนะนำ ได้ย่อรูปด้วย): ล็อกอินแอดมิน → ADMIN → "อัปโหลดรูปหลายรูปเข้า Google Drive" → เลือกไฟล์ทั้งหมด → UPLOAD_PHOTOS

เช็กว่ารูปขึ้นครบแล้ว ค่อยลบรูปเลขนศ.ออกจาก `assets/` ใน repo (เก็บ `images.png`, `LogoTSE37.png`, `logo-cn25*` ไว้)

## วิธีเปลี่ยนรูปหลังจากนี้

- **สมาชิก**: ล็อกอิน → เปิดการ์ดตัวเอง → 📷 CHANGE_PHOTO
- **แอดมิน**: เปิดการ์ดของใครก็ได้ → 📷 CHANGE_PHOTO หรือใช้อัปโหลดหลายรูปในหน้า ADMIN
- ใส่ไฟล์ลงโฟลเดอร์ Drive ตรง ๆ ก็ได้ ตั้งชื่อเป็น `<เลขนศ>.jpg`

## แก้ปัญหา

- **รูปไม่ขึ้น เห็นแต่ตัวอักษรย่อ**: เช็กว่าโฟลเดอร์แชร์เป็น "ทุกคนที่มีลิงก์" แล้ว
- **อัปแล้วขึ้น "เซสชันหมดอายุ"**: `FIREBASE_API_KEY` ผิด หรือ API key ใน Google Cloud จำกัด referrer ไว้ ให้ใส่ `SITE_ORIGIN` ให้ตรงกับโดเมนที่อนุญาต
- **อัปแล้วขึ้น "ไม่มีสิทธิ์"**: ล็อกอินด้วยเลขนศ. อื่น หรือเลขแอดมินไม่อยู่ใน `ADMIN_IDS`
